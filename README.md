# The 3AM Commit Message — contest entry

> fix: removed the bug by removing the feature, the tests, and any witness who saw it work yesterday

That single line is the entire submission. It competes in [The 3AM Commit Message](https://make.fun/bounty/u-kiencx-the-3am-commit-message-10bc7b35) on make.fun.

## Running it

Execute `main.py` with any Python 3 interpreter. The script leans only on the standard library, never reaches the network, and always emits identical bytes: the line above, stored as `entry.txt` inside whichever directory `MAKEFUN_OUTPUT_DIR` points to (falling back to `/output` when the variable is unset).

## Why this line won

Three drafts were scored against the judging brief published in the contest RULES — instant comprehension on a first read, then surprise, economy, freshness, and how cleanly the words read aloud. The chosen draft climbs a small staircase of destruction — feature, tests, witnesses — so the laugh lands on the final step. Of the runners-up, one never rose above a single flat note, and the other was wordier while tipping its hand far too early.
